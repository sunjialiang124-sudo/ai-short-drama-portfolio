# AI 短剧工作台 · 产品作品集

## 在线体验

**[点击进入 AI 短剧工作台](https://sunjialiang124-sudo.github.io/ai-short-drama-portfolio/)**

无需安装或启动本地服务，直接打开以上链接即可体验。

用于面试展示的可交互静态演示，呈现从剧本理解、导演设计、人工审核到生成提示词的制作流程。

## 展示内容
- 剧本与画面理解、导演级场面调度。
- 制作流程导航、历史案例与提示词展示。
- 演示审核与批注：仅保存在访客浏览器，可随时重置。

## 展示边界
这是独立作品集演示，不包含生产后台、模型密钥或业务数据库；不会调用模型、生成新视频或产生模型费用。历史案例状态以页面记录为准，演示审核不代表真实生产验收。

## 文件
- `index.html`：页面入口
- `app.js`：交互逻辑
- `data.js`：展示案例
- `style.css`：样式
- `lucide.min.js` / `LICENSE-lucide.txt`：图标库与许可证

项目案例仅用于作品展示；第三方组件遵循各自许可证。
